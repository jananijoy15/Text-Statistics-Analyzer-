📊 Text Statistics Analyzer

Text Statistics Analyzer is a simple web-based Text Analysis application that provides detailed statistical information about the entered text.

Live Application Link 
https://jananijoy15.github.io/Text-Statistics-Analyzer-/

✨ Features

- 📝 Analyze entered text
- 🔢 Count total words
- 🔤 Count characters
- 📄 Count sentences
- 📑 Count paragraphs
- 📏 Calculate average word length
- ⏱️ Estimate reading time
- ⚡ Real-time text analysis
- 📱 Mobile-friendly responsive interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How to Use

1. Open the application in a web browser.
2. Enter or paste text into the text area.
3. The application automatically analyzes the text.
4. View the different statistics displayed on the screen.

📊 Statistics Provided

Statistic| Description
Words| Total number of words
Characters| Total number of characters
Sentences| Total number of sentences
Paragraphs| Total number of paragraphs
Average Word Length| Average number of characters in each word
Reading Time| Estimated time required to read the text

💡 Example

Input:

Artificial Intelligence is changing the world.
It is used in many different industries.

Analysis:

Words: 13
Characters: 91
Sentences: 2
Paragraphs: 1
Average Word Length: 5.5
Reading Time: Less than 1 minute
